# Kalp Shah — Modern AI & Machine Learning Portfolio (V2)

A futuristic, high-performance developer portfolio built with pure Vanilla HTML5, CSS3, and JavaScript, replicating the aesthetic, dark/light theme, typography, and interactive AI Chatbot architecture of [`sreestats.in`](https://www.sreestats.in/).

---

## 🌟 Key Features

- **Cyberpunk Dark Theme (`#050505`) with Crimson Red (`#FF2A2A`) Accents**: Deep contrast, glow borders, and glassmorphism.
- **Oswald Display Typography**: Giant responsive watermark background branding (`KALP`, `ABOUT`, `SKILLS`, `PROJECTS`, `CONTACT`).
- **Signature Sliding Hover Buttons**: Smooth sliding crimson background fill on hover with glowing neon shadow.
- **Interactive AI Assistant Chatbot**: Floating chatbot widget in the bottom right corner answering queries about Kalp's background, machine learning projects, skills, education, and contact channels.
- **Live Theme Switcher**: Toggle between Dark & Light themes with localStorage persistence.
- **Real-Time Project Showcase**:
  1. **SpamShield AI**: Real-Time NLP Email Spam & Threat Detector with 96.0% accuracy.
  2. **Heart Disease Risk Prediction System**: Clinical risk assessment powered by ensemble Machine Learning (88.5% accuracy).
  3. **StudyMate AI**: Intelligent Academic Learning Companion for syllabus summarization and quiz generation.
- **Academic & Credentials**: Verified certifications from Google, IBM, Simplilearn, and BVM ML Club.
- **Mobile Responsive**: Custom mobile navigation drawer with sticky scroll-spy.

---

## 🚀 How to Run Locally

You can open `index.html` directly in any modern web browser or serve it using Python or Vite:

```bash
# Using Python 3
python -m http.server 8080

# Or using npx serve
npx serve .
```

Visit: `http://localhost:8080`
